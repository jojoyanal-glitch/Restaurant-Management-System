# Restaurant Management System

A desktop application developed using Java Swing and Object-Oriented Programming (OOP) principles.

## Features
- Restaurant information management
- Employee management
- Customer management
- Table reservation and availability checking
- Object-oriented class design

## Technologies Used
- Java
- Java Swing
- Object-Oriented Programming (OOP)

## Project Structure
The system includes the following main classes:
- `Restaurant`
- `Employee`
- `Customer`
- `People`
- `Table`

## Purpose
This project was developed to practice OOP concepts, class relationships, inheritance, encapsulation, and object management in Java.
